# SpeedJobs ⚡

Lightning-fast hiring platform for express job matches, 1-click applications, flash hiring, and rapid interviews.

## Features

- **Express Job Discovery**: Filter by 24h Flash roles, remote eligibility, match compatibility, and salary.
- **1-Click Speed Apply**: Transmit candidate SpeedPass in under 1 second with pre-filled elevator pitches.
- **Candidate SpeedPass™**: Verified profile management with live skill compatibility matching against all active jobs.
- **Fast Tracker Pipeline**: Monitor applications across 4 express stages (`Applied` → `Fast Screened` → `Speed Interview` → `Offer Extended`).
- **15-Minute Speed Interview Simulator**: Built-in sprint practice room with real-time countdown, stage prompts, scratchpad, and self-review scorecard.
- **Employer Command Center**: Post flash jobs with 1-click templates and manage applicants pipeline with rapid interview invitations.

## Development

```bash
npm install
npm run dev
```

The application runs on port 3000 at `0.0.0.0:3000`.
